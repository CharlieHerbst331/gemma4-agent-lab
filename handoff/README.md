# handoff/

Start here if you are a new agent (Antigravity or otherwise).

1. `HANDOFF.md`: goal, rules and limits, architecture, version history, diagnosis, the v22-1
   next step, and pitfalls.
2. `SETUP.md`: Mac setup, GitHub and Kaggle auth, verification commands.
3. `scored-archives.json`: sha256 of every archive already submitted. Never resubmit one.
4. `../AGENTS.md` and `../.agents/rules/`: the rules you follow (always on in Antigravity).
5. `../scripts/handoff/` and `../.agents/skills/`: the pack / dev-13 / analyze / submit loops.
